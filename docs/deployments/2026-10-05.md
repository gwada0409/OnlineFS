## Confirmed failures and fixes

1. AutoID Nginx retained backend address `172.18.0.4` after Docker recreated the backend at `172.18.0.3`. Employee login returned 502. Both Nginx configurations now use Docker DNS (`127.0.0.11`) and a shared upstream with `resolve` and a 10-second DNS lifetime. Both running images and canonical source configurations were updated.
2. Production CORS allowed only internal addresses. Added the two HTTPS public domains, preserving existing internal origins. SignalR negotiation now returns 200 and the matching allowed origin. Extended OnlineFS hub read timeout; ordinary API requests no longer send WebSocket upgrade headers.
3. `/api/category` returned 500 because its nested projection required SQL APPLY, unsupported by SQLite. The controller now materializes the included graph using split read-only queries before mapping department DTOs.
4. Some small screen sizes hid every Admin login mode switch. A final responsive rule keeps the mobile switcher visible.
5. The employee balance detail/editor panel was hidden below desktop width. It is now visible on small screens.
6. Previously prepared HR default login routing and selected balance snapshot refresh changes were deployed with this release.
